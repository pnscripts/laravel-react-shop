# Upgrade notes: Phase 13 (hardening, 1.0)

## Required actions

1. **`APP_URL`:** set it to the shop's real address. Once installed, requests for other hosts are refused. Add other domains to `PNSHOP_TRUSTED_HOSTS`, comma-separated.
2. **Scheduler:** make sure it runs (`php artisan schedule:run` every minute). A new hourly job cancels unpaid orders (see below).
3. **Plugins with storefront scripts:** the script must now be in a subfolder, such as `dist/storefront.js`. The bundled handling-fee plugin already is.

## Behaviour changes

- **Stripe return page:** it only links to the order with a signed link when the Checkout Session matches. Before, any visitor could get a signed link to any order by guessing payment ids. Update the Stripe plugin on every shop that uses it.
- **Unpaid orders:** pending orders still unpaid after *Settings → Orders → Cancel unpaid orders after* (default 168 hours) are cancelled and their stock released. Set it to 0 to turn this off.
- **Order links:** guest order links in emails and the Store API expire after 180 days (`PNSHOP_ORDER_LINK_DAYS`).
- **Staff permissions:**
  - Staff can no longer assign roles or add permissions they do not hold themselves.
  - Only administrators can edit administrator accounts.
  - Restoring a page revision follows the custom-HTML permission.
- **Coupons:** wrong codes are limited to 10 per 10 minutes per visitor.
- **Installer:** an unreachable database shows a 503 page instead of the installer, and the database step no longer shows raw connection errors.
- **Plugin assets:** only static files are published to `public/extensions/<id>/`.
- **Admin API lists:** they load translations and order lines in batches (fewer queries).

## For developers

- **Locks:**
  - `CartRepository::lockedLines()`: checkout reads the cart under a row lock and empties it in its transaction.
  - `RefundService::refund()` and `ReturnService::refund()` take a cache lock.
- **Locking read:** `Redemptions` counts per-customer uses with a locking read.
- **`Translatable::allTranslations()`:** eager-load it for lists that show every language.
- **`pnshop:orders:cancel-unpaid`:** a new command (with `--dry-run`).
- **CI:** a bundle-size budget (`scripts/check-bundle-size.mjs`), and query-count tests for the product page, cart, checkout, order page and API lists.
