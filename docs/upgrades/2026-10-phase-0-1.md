# Upgrade notes: Phase 0 (safety) and Phase 1 (versions)

Date: 2026-10-01. Applies to anyone running the starter-kit version of this repository.

## Required actions after pulling

1. `composer install` and `npm ci`. PHP **8.4+** and Node **22.12+** (24 LTS recommended) are now required.
2. `php artisan migrate`. This runs `2026_10_01_000000_preserve_order_history_on_catalog_deletes`, which adds `product_title` / `product_sku` to `order_items` (backfilled from products) and changes foreign keys so deleting catalog rows no longer deletes order lines.
3. The seeder no longer creates `test@example.com`. If you seeded that account before, **delete it or change its password**. Create an administrator with:
   ```bash
   php artisan pnshop:create-admin you@example.com --name="Your Name"
   ```
4. Review `.env`. `.env.example` now defaults to `APP_ENV=production`, `APP_DEBUG=false`, `LOG_LEVEL=warning`, `SESSION_ENCRYPT=true` and `INERTIA_SSR_ENABLED=false`. Set `APP_ENV=local` / `APP_DEBUG=true` for development, and `SESSION_SECURE_COOKIE=true` on HTTPS sites.
5. Existing shopping carts in sessions are discarded once: the cart moved from a serialized PHP object to `product_id => quantity`.
6. `npm run build` (and `npm run build:ssr` if you use SSR).

## Behaviour changes

| Area | Before | After |
|---|---|---|
| Cart prices | Copied into the session when added; checkout charged the stored copy | Read from the database on every request; checkout charges the current price |
| Cart quantity | Each add checked separately against stock | Running total checked against stock; max 100 per line |
| Checkout errors | Any exception message shown to the shopper | Only expected cart/checkout messages shown; other errors are reported to logs |
| Stock | Decremented in checkout order with a check-then-act | Rows locked in id order; conditional decrement can never go negative |
| Cancelling an order | Stock stayed decremented | Stock returned; reopening takes it again or is refused |
| Rate limits | Login only | Also cart (60/min), checkout (5/min, 20/h per IP, 10/h per email), register, password reset, confirm password |
| Order history | Deleting a product/category cascaded into order lines | Lines keep title/SKU; product link set to null; categories with products cannot be deleted |
| Discounts | Discount price could exceed the price | Must be lower than the price |
| Product page | Attribute values were always empty (bug) | Values shown |
| Telescope / Scramble | Production dependencies | Telescope dev-only (local env); Scramble removed until the API exists |

## Deliberately deferred

- **ESLint 10:** `eslint-plugin-react` 7.37.5 (latest) declares support only up to ESLint 9.
- **TypeScript 7:** `typescript-eslint` does not support it yet, and `tsconfig.json` uses `baseUrl`, which TS 7 removed.
- **Larastan level 7:** 47 findings, nearly all in the legacy models and translation trait that Phases 3–4 replace. New core modules (Phase 2) are written to level 7, and the level is raised then.
- **Wayfinder (replacing Ziggy):** still 0.x; 28 call sites.
- **`@inertiajs/vite` plugin:** a small typed resolver (`resources/js/lib/resolve-page.ts`) is used instead; Phase 9 (themes) needs custom page resolution anyway.
