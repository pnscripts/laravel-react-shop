# Upgrade notes: 1.1.1

Fixes from the 1.1 audit. Plugin and theme contracts do not change.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
```

## Required actions

1. **Behind a proxy:** if the shop runs behind a load balancer, Cloudflare or a reverse proxy, set `TRUSTED_PROXIES` in `.env` (the proxies' IPs or CIDR ranges, comma-separated, or `*`). Without it, every visitor shares the proxy's IP for rate limits.

## Behaviour changes

- **Unpaid orders:** the hourly cancellation skips orders that have shipped. Orders with nothing to pay are marked paid when placed.
- **Staff accounts:** staff with *manage admin users* can only edit or delete accounts whose permissions they hold themselves.
- **Customers:**
  - A password change or reset signs out the customer's other browsers and revokes their Store API tokens, so apps must sign in again.
  - Sign-in is limited to 20 attempts a minute per IP, besides the per-email limit.
- **Stock:** staff without `catalog.inventory.manage` see the stock fields read-only. The Admin API refuses `stock` in product and variant updates from tokens without it (403).
- **Coupons:** reopening a cancelled order fails with a message when one of its offers has been used up since.

## New

- **Email verification:** *Settings → Customers → Require a verified email address*. Off by default; when on, existing customers without a verified address are asked to verify too.

## For developers

- **Database:** `promotion_redemptions.released_at`. A cancelled order's uses are kept and marked released instead of deleted. `PromotionRedemption` queries see only uses in force (global scope `in_force`).
- **Events:** `PnShop\Sales\Events\OrderReopening` runs inside the reopening transaction; throw an `OrderException` to refuse.
- **`OrderWorkflow::transition(..., when: fn (Order $locked) => bool)`:** checks the locked order before changing it.
- **`PnShop\Customer\Models\User`:** now implements `MustVerifyEmail`; `hasVerifiedEmail()` is true while verification is not required.
