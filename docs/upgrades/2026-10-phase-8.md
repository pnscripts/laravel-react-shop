# Upgrade notes: Phase 8 (extensions)

## Required actions

1. `composer install` (adds `composer/semver`).
2. `php artisan migrate`. New tables: `extensions` and `extension_migrations`.
3. Create the `extensions/` folder if you want to add plugins as folders.

## Behaviour changes

- **New admin page:** Admin → Extensions, for staff with the new **system.extensions.manage** permission (administrators by default).
- **Core version:** the version is now `0.8.0-dev`. Plugins declare the versions they support in `requires.pnshop`.

## For developers

- See [plugins](../extensions/plugins.md).
- **Boot list:** enabled plugins boot from `bootstrap/cache/pnshop-plugins.php`. The extension manager rewrites it, so don't edit it.
