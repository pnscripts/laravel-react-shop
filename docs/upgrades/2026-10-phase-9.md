# Upgrade notes: Phase 9 (themes)

## Required actions

1. No new tables. The active theme is a setting (`appearance.theme`, default `pnshop/default`).
2. `npm run build` as usual for the default theme. Other themes ship prebuilt; to build one from source run `npm run build:theme -- <vendor/name>`.
3. Make sure the web server can write to `public/themes/` (themes are published there on activation).

## Behaviour changes

- **New admin page:** Admin → Appearance → Themes, with the new permission **appearance.themes.manage**.
- **Default theme settings:** the default theme has a brand colour and corner setting (Admin → Settings → *Theme: PN Shop Default*). The defaults match the previous look.
- **SSR:** it is switched off while a theme other than the default is active.
- **Core version:** `0.9.0-dev`.

## For developers

- **New setting types:** `color` (hex) and hidden schemas (`SettingsSchema::hidden()`).
- **Prettier and ESLint:** they now cover `themes/` and `scripts/`, and ignore built `dist/` folders.
