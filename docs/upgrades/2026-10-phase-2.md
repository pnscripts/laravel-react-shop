# Upgrade notes: Phase 2 (core foundation and admin panel)

## Required actions

1. `composer install`. This publishes Filament's precompiled assets through `php artisan filament:upgrade` (no Node needed on the server).
2. `php artisan migrate`. New tables are `settings`, `admin_users`, `admin_password_reset_tokens`, the role/permission tables and `activity_log`.
   - Users that had `users.is_admin = 1` are copied to `admin_users` with their **existing password** and the administrator role. The `is_admin` column is dropped, and their customer accounts remain.
   - Permissions and built-in roles are created automatically at the end of `migrate`.
3. Sign in at **`/admin/login`** (not `/login`). If no staff account exists, run `php artisan pnshop:create-admin you@example.com`.
4. `npm run build` (the storefront now reads its name from the *Store name* setting).

## Removed

- The React admin pages (`/admin/products`, `/admin/orders` as Inertia pages), `EnsureUserIsAdmin`, the `admin` route middleware alias, `User::isAdmin()` and the `UserFactory::admin()` state. Their replacements are the Filament resources at the same URLs.
- The "Admin" links in the storefront header and the customer dashboard.

## New

- Filament 5 admin with dashboard widgets, products, orders (view and status changes), admin users, roles, settings and the activity log.
- Separate `admin` guard, the `admin_users` password broker, and role-based permissions (spatie/laravel-permission).
- `pnshop:create-admin` (now creates staff accounts) and `pnshop:permissions:sync`.
- `core/` module layout and extension kernel: see [development/core-modules.md](../development/core-modules.md).
