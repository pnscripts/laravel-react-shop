# Upgrade notes: 1.2.0

Catalog and storefront gaps found by the audit of 1.1. Plugin and theme contracts stay compatible: the shop page and product cards receive new props, and existing props are unchanged.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
php artisan optimize && php artisan queue:restart
```

One migration adds `products.is_featured` and `product_variants.low_stock_threshold`.

## Required actions

- **Rebuild themes:** non-default themes must be rebuilt (`npm run build:theme -- <vendor/name>`) to get the search box, the sort menu and the deeper category rows. The bundled Aurora theme already includes the new product card text.

## New

- **Shop page:**
  - a search box (product titles in the visitor's language);
  - sorting by newest, price or name;
  - category rows at any depth.
- **Featured products:** *Featured on the home page* in the product form. Featured products come first in the home page's list, also in the Admin API (`is_featured`, `filter[is_featured]`).
- **Low stock per variant:** *Low stock at* in the variant form (Admin API `low_stock_threshold`). Empty means the default of 5.
- **Stock history:** a *Stock history* tab on each product lists every movement of its variants.

## Behaviour changes

- **Product page specifications:** they list every attribute the product has values for, with all the values of multi-select attributes, whatever category the attribute is linked to. Before, only attributes of the primary category were shown, and only one value each.
- **Product cards:** a product that sells on backorder shows *Available to order* instead of *Out of stock*.

## For theme authors

These page props are new and optional; older themes ignore them:

- `shop/index`:
  - `filters.q` and `filters.sort`;
  - `sorts` (list of `{key, label}`);
  - `categories[].children[].children` at any depth.
- Product cards: `backorder` (boolean).
