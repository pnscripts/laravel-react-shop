# Upgrade notes: Phase 7 (CMS and SEO)

## Required actions

1. `composer install` (adds `symfony/html-sanitizer` as a direct dependency).
2. `php artisan migrate`. New tables: `pages`, `page_translations`, `content_blocks`, `page_revisions`, `menus` (with empty *Header* and *Footer* menus), `menu_items` and `menu_item_translations`.
   Products, categories and their translations also get `meta_title` and `meta_description`.
3. If your web server serves `public/robots.txt` directly, remove the old copy. It is deleted from the repository; robots.txt is now generated.
4. `npm run build`.

## Behaviour changes

- **Unknown paths:** any address the shop does not handle now goes through the CMS (`/{slug}`). Paths that don't match a live page still return 404.
- **Menus and footer:** the storefront header shows the *Header* menu once it has items; until then it shows the *Shop* link. The new footer shows the *Footer* menu.
- **SEO tags:** every page now prints a description, canonical, hreflang alternates, robots, Open Graph and JSON-LD.
- **New URLs:** `/sitemap.xml` and a generated `/robots.txt`.
- **Language switcher:** on products and pages with translated slugs it now goes to the translated address.
- **Homepage:** a page marked *Use as the homepage* replaces the default home.

## For developers

- **Block types:** register with `PnShop\Cms\Blocks\BlockRegistry` and render with `registerBlock()` in `@/components/blocks`. See [pages and blocks](../cms/pages-and-blocks.md).
- **Fallback route:** the fallback route is now `PageController@show`. Register your own routes normally; they take precedence.
