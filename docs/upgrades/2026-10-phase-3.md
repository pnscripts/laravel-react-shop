# Upgrade notes: Phase 3 (localization and money)

## Required actions

1. `php artisan migrate`:
   - **Languages, currencies, countries:** creates English (default), Bulgarian, US dollar (default), euro (inactive) and all ISO countries.
   - **Translation tables:** creates `product_translations`, `product_category_translations`, `product_attribute_translations` and `product_attribute_value_translations`. Existing rows of the old polymorphic `translations` table are copied (except default-language rows, which the entity columns already hold), and the old table is dropped.
   - **Money:** converts `products.price`, `products.discount_price`, `order_items.price` and `order_items.discount_price` from decimals to integer minor units of the default currency, and adds `currency` to `orders` and `order_items`. An order line discount of `0` becomes `null`.
2. `npm run build`.
3. Optional: set **Admin → System → Settings → Localization → Store timezone**.

## Behaviour changes

- Storefront pages are available under language prefixes (`/bg/...`). The default language stays unprefixed, and `/<default>/...` redirects to it.
- Prices are formatted on the server in the visitor's language. The storefront no longer formats every amount as USD in the browser.
- Shopper messages, validation errors, order status names and dates follow the visitor's language.
- The storefront no longer publishes admin, Livewire, debug or storage route names to the browser.
- Home and shop pages run 2 and 4 queries in the default language (previously 34 and 52), and 4 and 7 in a translated language.

## For developers

- `App\Traits\HasTranslations` and `App\Models\Translation` are removed. Use `PnShop\Localization\Concerns\Translatable` (see [development/localization-and-money.md](../development/localization-and-money.md)).
- Prices are `Brick\Money\Money` objects, not floats or decimal strings. Frontend price props are `{ amount, minor, currency, formatted }`, and `formatMoney()` is removed.
- `ShoppingCartService::getTotalPrice()` / `getFinalPrice()` return `Money`.
