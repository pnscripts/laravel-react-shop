# Upgrade notes: Phase 12 (installer and updater)

## Required actions

1. Run `php artisan migrate`. It creates `system_versions` and records the existing shop as installed (`adopt`), because it has staff accounts.
2. From now on, update with `php artisan pnshop:update` after replacing the code. See [updating](../installation/updating.md).

## Behaviour changes

- **Redirect to the installer:** until PN Shop is installed, every page leads to `/install`. Set `PNSHOP_ENFORCE_INSTALL=false` to switch this off, which the test suite does.
- **Installed shops:** a shop with staff accounts, or with the lock file `storage/app/pnshop-installed.json`, counts as installed, and `/install` returns 404.
- **New admin page:** System → Version and updates, with the permission `system.settings.manage`.
- **MySQL and PostgreSQL fixes** (found by installing on MySQL 8 and running the test suite on MySQL 8 and PostgreSQL 16):
  - **Long names:** four index and foreign key names were longer than MySQL's 64-character limit.
  - **Redirects:** `redirects.from_path` is limited to 768 characters, so its unique index fits MySQL's key size.
  - **Order totals correction:** the 2026-10-05 migration now finds orders without adjustments on MySQL too (`whereJsonLength` instead of comparing JSON to `'[]'`).
  - **Search:** product title searches ignore case on PostgreSQL too (`whereLike`).
  - **Deleting a product:** it now unlinks its order lines before the delete, so the outcome does not depend on the order in which the database runs its cascades.
  - **SQLite:** existing SQLite databases are not affected.

## For developers

- **Commands:** `pnshop:install` and `pnshop:update`. `php artisan about` shows the code and database versions.
- **Backups:** `PnShop\Installer\Contracts\BackupDriver` is the backup contract, with `LocalBackup` as the default.
- **Middleware:** `InstallGate` is the first global middleware. `LocalizeRequest` skips installer requests.
- **Tests:** the suite also passes against MySQL 8 and PostgreSQL (run it with `DB_CONNECTION=mysql|pgsql DB_HOST=… DB_DATABASE=<empty test database> …`). CI runs both on pull requests.
- **Tests and ids:** do not hard-code record ids in tests. MySQL and PostgreSQL keep counting auto-increment ids across rolled-back tests.
